## Overview

Layout creates structure and visual flow. morphink uses Grid and Stack as primary building blocks, with Spacing tokens ensuring consistency.

## Principles

- Use Grid to define primary axes and alignment
- Use Stack to create vertical rhythm
- Adjust density gradually; avoid over-packing
- Use `space.*` tokens for consistent spacing

## Grid vs Stack

Grid is suited for area-based composition where columns and ratios are explicit. Stack is suited for flow-based composition, useful for controlling vertical and horizontal spacing.

## Responsive

Adjust column count and spacing based on viewport width to balance readability and information density. On smaller screens, reduce columns and prioritize vertical rhythm.
