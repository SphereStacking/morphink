## Notes for designers

- Brand colors are organized under `color.primary.base` / `color.secondary.base` / `color.tertiary.base` / `color.accent.base`.
- Text colors use `color.foreground.base` and `color.muted.foreground`.
- Surfaces are organized under `color.background.base` / `color.card.base` / `color.muted.base`.
- Borders use `color.border.base`.
