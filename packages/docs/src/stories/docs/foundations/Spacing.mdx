## Utilities

```
ink-p-{space}
ink-px-{space} / ink-py-{space} / ink-pt-{space} / ink-pr-{space} / ink-pb-{space} / ink-pl-{space}
ink-m-{space}
ink-mx-{space} / ink-my-{space} / ink-mt-{space} / ink-mr-{space} / ink-mb-{space} / ink-ml-{space}
ink-gap-{space}
ink-space-x-{space} / ink-space-y-{space}
ink-space-x-reverse / ink-space-y-reverse
```

Example: `ink-p-md`, `ink-mx-lg`, `ink-gap-2xl`, `ink-space-x-sm`


## Notes for designers

- Align spacing using Stack / Grid; minimize individual margin adjustments.
- Content with the same density should use the same `space.*` tokens.
