## Utilities

```
mi-p-{space}
mi-px-{space} / mi-py-{space} / mi-pt-{space} / mi-pr-{space} / mi-pb-{space} / mi-pl-{space}
mi-m-{space}
mi-mx-{space} / mi-my-{space} / mi-mt-{space} / mi-mr-{space} / mi-mb-{space} / mi-ml-{space}
mi-gap-{space}
mi-space-x-{space} / mi-space-y-{space}
mi-space-x-reverse / mi-space-y-reverse
```

Example: `mi-p-md`, `mi-mx-lg`, `mi-gap-2xl`, `mi-space-x-sm`

## Notes for designers

- Align spacing using Stack / Grid; minimize individual margin adjustments.
- Content with the same density should use the same `space.*` tokens.
