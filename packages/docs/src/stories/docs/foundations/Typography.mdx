## Overview

Typography determines information priority and readability. ink-ui manages size, line height, and weight through tokens.

## Notes for designers

- Increment heading levels one at a time; avoid skipping levels.
- Limit text roles to three levels per surface.
- Labels and captions should not be more prominent than body text.
