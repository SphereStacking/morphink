## Utilities

### Border Color

```
mi:border-{color}
```

Example: `mi:border-primary`, `mi:border-accent`

### Border Width

Border width is controlled via component props:

- `Box` — `border` prop (`true` | `'default'` | `'strong'` | `'heavy'`)
- `Divider` — `weight` prop (`'default'` | `'strong'` | `'heavy'`)

## Usage Guidelines

- Use `default` (1px) for standard separators and card outlines.
- Use `strong` (2px) when extra visual emphasis is needed.
- Reserve `heavy` (4px) for decorative accents or key section highlights.
- Prefer semantic tokens (`border.width.default` etc.) over alias tokens (`border.width.1` etc.).
