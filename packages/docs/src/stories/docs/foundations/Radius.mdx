## Overview

角の形状はコンポーネントの印象と視覚的なやわらかさを調整します。ink-ui では radius トークンで一貫性を保ちます。

## Utilities

```
ink-rounded-{radius}
ink-rounded-t/b/l/r-{radius}
ink-rounded-tl/tr/bl/br-{radius}
```

例: `ink-rounded-md`, `ink-rounded-full`, `ink-rounded-tl-sm`
