## Utilities

```
mi:rounded-{radius}
```

Example: `mi:rounded-md`, `mi:rounded-full`

## Usage Guidelines

- Use `md` as the default for cards and panels.
- Use `full` for circular elements like avatars and badges.
- Keep radius consistent within the same visual group.
